# Assignment 2: Structured webpage: navigation, tables and forms

## Run

From the repository root run `npm start`, then open `http://localhost:3000/assign_02/`. No dependencies are needed for these static pages. Keep this terminal running.

## Implementation

1. A navigation link with a fragment scrolls to an element with that id.

2. Tables represent related data; caption explains the table and scope links headings with rows or columns.

3. Labels identify inputs. Required and email types provide browser validation. The demonstration intercepts submit and does not send data.
