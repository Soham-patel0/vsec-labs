# Assignment 1: Responsive semantic webpage

## Run

From the repository root run `npm start`, then open `http://localhost:3000/assign_01/`. No dependencies are needed for these static pages. Keep this terminal running.

## Viva: explain the implementation

1. Semantic elements describe purpose: header introduces the page, nav links sections, main holds primary content, article groups independent content, aside adds supporting notes, footer closes the page.

2. CSS Grid uses auto-fit and minmax to stack cards when the screen narrows. The viewport tag makes mobile sizing meaningful.

3. A media query changes padding on small screens. Keyboard focus and the skip link improve navigation.

## Demonstration checklist

Open at desktop and narrow mobile widths. Follow navigation links, tab through controls, and verify cards stack without horizontal page overflow.
